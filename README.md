One commit message for a bug fix that made everything worse, written for the
[make.fun "Worst Fix Ever: Funniest Commit Message" bounty](https://make.fun/c/u-deysumbrella-worst-fix-ever-funniest-commit-message-3f1d9722).

## The entry

> `fix(db): plugged the leak by deleting the database (leak gone, data too)`

72 characters. The leak is fixed. The database is gone. So is the data.

## How it works

`main.py` (Python standard library only, fully deterministic) writes that single
line to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`).

Run it locally:

```sh
python3 main.py
```
